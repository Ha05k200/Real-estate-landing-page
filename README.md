# Real Estate Landing Page

## Run in Command Prompt

1. Open Command Prompt.
2. Run:

```bat
cd "C:\Users\harshitha reddy\IdeaProjects\realestate landing page"
run-local.bat
```

3. Browser opens at:

`http://127.0.0.1:5500/`

```bat

```

Then open:
`http://127.0.0.1:8080/`
